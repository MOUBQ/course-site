# 致 娇姐

一个浪漫甜系的一页式表白网页，托管在 GitHub Pages 上。

- 粉色渐变 + 浮动爱心背景
- 一封手写风格的情书
- 最后的小互动：愿不愿意给强哥哥一个机会

在线访问：`https://<你的用户名>.github.io/course-site/`

## 目录结构

```
course-site/
├── index.html          # 表白页（单页应用，含脚本）
└── css/style.css       # 浪漫甜系样式
```

## 说明

- 纯前端，无构建依赖，`index.html` + `css/style.css` 即可运行。
- 本地预览：直接双击 `index.html`，或 `npx serve` / `python -m http.server` 起本地服务器。
- 推送改动后，等 1~3 分钟 GitHub Pages 自动更新。
